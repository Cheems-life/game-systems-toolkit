# 命令行示例

`quickstart` 验证使用者可以只通过公开头文件和 `designer::core` 链接库。
它不是背包示例。背包规则实现后，在这里添加独立示例目录。

运行方式见 [构建指南](../docs/building.md)。

`inventory` 演示添加、拆堆、满包失败、移除和交换，并检查容量不足时状态未变。

`inventory/storage_demo.cpp` 演示拾取整箱、仓库存入/取出、多容器存档与统一恢复。`--load` 模式不会修改文件，便于验证独立进程加载。具体命令见构建指南。

`economy/main.cpp` 演示多币钱包、购买、背包不足失败、请求重放，以及含余额/容器/回执的统一存档；`--load` 在独立进程加载后重放原请求。
