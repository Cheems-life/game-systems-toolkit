## 场景与问题

先建立最小可编译入口，验证学习项目可以脱离引擎运行。

## 数据、接口与关键规则

C++17、CMake、独立静态库目标和命名空间别名；core 当前仅提供版本查询，不承担尚未实现的生命周期框架。示例和测试在顶层默认启用，嵌入其他工程时默认关闭。

## 为什么这样设计与替代方案

与直接建立 Godot 项目相比，独立库让领域规则可在命令行验证。与先建万能框架相比，只提供真实需要的入口可避免过早抽象。每个模块仅声明实际依赖，不强制继承 core 基类。

## 实现步骤与提交边界

配置 CMake → 编译 core → 编译并运行 quickstart → 通过公开头文件链接 → 使用外部 CMake 工程验证集成。
