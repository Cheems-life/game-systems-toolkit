领域规则与引擎、存储、网络及第三方 SDK 通过明确接口连接。仅依赖实际需要的模块，依赖关系在实现前记录；不默认依赖所有基础模块。服务类模块的客户端接口不等于完整后端实现。

## 商业级验收重点

- 明确正常路径、边界条件、失败处理和资源清理；对关键规则进行可重复验证。
- 若维护持久化状态，说明数据版本、迁移、兼容和恢复策略。

- 声明性能预算、支持平台和适用限制；提供可运行的最小示例与集成说明。
