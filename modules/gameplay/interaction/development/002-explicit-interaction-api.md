## 问题与选择

Book::query 无法说明查询内容，execute 无法说明执行内容，receipt 也不像查找函数。改为 check_interaction_availability、execute_interaction、find_interaction_receipt。为头文件补参数名，明确目录、点、请求和事件序号。没有将查询命名为 can_interact，因为结果包含失败原因而非只有 bool。

## 契约、实现与验证

参数和返回类型不变：资格查询不处理距离权限，执行只记录成功凭证，玩家协调器才同时推进任务。重放优先级、一次性、模式冲突、历史上限、事件递增和失败不变均不变。snapshot/restore 维持常规名称。

同步核心实现、玩家调用、所有示例和测试。已有核心/共享玩家/存档/分配异常回归均随完整测试运行；没有新增算法，无需写重复行为的新测试。独立外部集成及其余最终结果见玩家命名记录。

保留用户学习注释并修正笔误。旧 API 不留转发，调用方需更名，文件格式无需变更。原步骤 001 的规则仍有效，仅名称被本记录替代。
